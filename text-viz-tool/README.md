# 文本可视化工具

一个功能强大的文本可视化 Web 应用，可以将文本内容转换为多种可视化形式，包括词云、时间线、流程图、图表、思维导图、日历和照片墙。

## ✨ 特性

### 📝 文本输入与智能解析
- 支持直接粘贴文本
- 支持上传 .txt 和 .md 文件
- **改进的分词算法**：完整识别年份（2023）、专有名词（ChatGPT、AlphaGo）、英文缩写
- **自定义关键词**：用户可以指定要特别关注的关键词
- **高级解析选项**：可配置最小词长、最大关键词数、是否提取事件、是否按时间排序
- 自动识别关键词、日期、事件等结构化信息
- 提供示例文本快速体验

### 🎨 多种可视化模板

1. **词云** - 展示文本中的高频关键词,字体大小反映词频
2. **时间线** - 按时间顺序展示事件,支持日期自动识别
3. **流程图** - 可拖拽的交互式流程图,展示事件序列
4. **图表** - 多维度数据统计图表（柱状图、饼图、折线图）
5. **思维导图** - 树形结构展示概念关系
6. **日历** - 在日历上标注事件,支持事件列表查看
7. **照片墙** - 卡片式展示,支持事件和关键词混合展示

### ✏️ 数据编辑器
- **关键词编辑**：添加、删除、修改提取的关键词及其出现次数
- **事件编辑**：添加、删除、修改事件的标题、内容和日期
- **统计信息查看**：查看文本的详细统计数据
- **实时生效**：编辑后的数据立即反映到所有可视化视图

### 🎛️ 可视化定制
- 自定义颜色方案
- 调整字体大小
- 自定义图表尺寸
- 支持实时预览

### 💾 导出与分享
- 导出为 PNG/JPG 图片
- 导出为 PDF 文档
- 导出为 JSON 数据
- 一键分享功能

### 📱 响应式设计
- 适配桌面和移动设备
- 流畅的用户体验
- 现代化的界面设计

## 📖 使用指南

### 1. 输入文本
- 在文本框中粘贴或输入文本内容
- 或点击"上传文件"按钮上传文本文件
- 或点击"加载示例"查看演示

### 2. 配置解析选项（可选）
- 点击"高级解析选项"展开配置面板
- 添加自定义关键词（特别关注的词）
- 设置最小词长、最大关键词数
- 选择是否提取事件、是否按时间排序

### 3. 解析文本
- 点击"解析文本"按钮
- 系统将自动提取关键词、日期、事件等信息
- 查看解析成功提示（显示找到的关键词和事件数量）

### 4. 编辑解析数据（可选）
- 在"解析数据编辑器"中查看和编辑提取的数据
- 关键词标签页：添加、修改、删除关键词
- 事件标签页：添加、修改、删除事件及其日期
- 统计信息标签页：查看文本统计数据

### 5. 选择可视化模板
- 从7种可视化模板中选择一种
- 每种模板都有独特的展示效果

### 6. 导出结果
- 选择导出格式（PNG、JPG、PDF、JSON）
- 点击"导出"按钮保存文件
- 或点击"分享"按钮分享链接

## 🎯 核心功能实现

### 文本解析算法（V2.0 改进版）

**智能分词**
- ✅ 完整识别4位年份（2012、2023等）
- ✅ 识别专有名词（AlphaGo、ChatGPT、GPT-3等）
- ✅ 识别英文缩写和驼峰命名（AI、ImageNet等）
- ✅ 识别字母数字组合（GPT-3、BERT等）
- ✅ 中文词语提取（2-4字词组合）
- ✅ 扩展的停用词过滤

**关键词提取**
- 词频统计 + 权重归一化
- 支持用户自定义关键词
- 可配置最小词长和最大数量

**日期识别**
- 使用 chrono-node 自动识别英文日期
- 额外支持中文年份格式（2023年）
- 自动去重和排序

**事件提取**
- 基于日期和事件关键词（发布、推出、完成等）
- 自动按时间排序
- 支持可选的句子时间排序

**文本排序**
- 可选按时间顺序重排句子
- 有日期的句子优先，按时间顺序
- 无日期的句子保持原顺序

### 可视化渲染
- 词云：Canvas 渲染,支持自定义颜色和大小
- 时间线：Ant Design Timeline 组件
- 流程图：ReactFlow 交互式流程图
- 图表：ECharts 多维度图表
- 思维导图：ECharts Tree 图
- 日历：Ant Design Calendar 组件
- 照片墙：CSS Grid 响应式布局

## 💡 常见问题

**Q: 支持哪些语言？**
A: 目前主要支持中文和英文混合文本。

**Q: 导出的图片质量如何？**
A: 使用 2x 缩放比例确保高清输出。

**Q: 可以处理多大的文本？**
A: 建议文本长度在 10,000 字以内,过长可能影响性能。

**Q: 日期识别不准确怎么办？**
A: 建议使用标准日期格式,如"2023年1月1日"或"2023-01-01"。
